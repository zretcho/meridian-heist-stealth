**The Meridian Heist** — a 2D top-down stealth game. You are a quiet thief in a sleeping museum, three floors of patrolling guards between you and the Meridian Star. Slip past their vision cones, hide in the bushes, sneak through the dark corners, toss a coin to turn a guard's head, steal the Star, and reach the green EXIT — unseen. Guards grow suspicious before they raise the alarm, so a near miss is a warning, not a sentence.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080/index.html in desktop Chrome. Or serve `game/` with any static server and open `game/index.html`.

**Controls:** WASD / arrow keys move · Shift sneaks (slow, quiet, harder to spot) · Click tosses a coin to distract a guard · R restarts the floor · P pauses.
